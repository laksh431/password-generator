# Project Statement

## Project Title

Password Generator

## Problem Statement

Creating strong and random passwords manually can be difficult and time-consuming. This project provides a simple Python-based solution to generate random passwords according to the user's requirements.

## Scope

The project takes the minimum password length as input and allows the user to choose whether numbers and special characters should be included. Based on these requirements, the program generates and displays a random password.

## Target Users

- Students
- Computer users
- Anyone who wants to generate random passwords

## High-Level Features

- Accept minimum password length
- Include numbers in the password
- Include special characters
- Generate random passwords
- Check the selected requirements
- Display the generated password

## Technologies Used

- Python
- Random Module
- String Module
